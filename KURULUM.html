Poliklinik Defteri: Kurulum Kılavuzu

Bu kılavuz uygulamayı yayına almayı, Google Drive eşitlemesini açmayı, bilgisayara ve Android telefona kurmayı anlatır. Kurulum bir kez yapılır, toplam 30–40 dakika sürer.

Nasıl çalışır? Uygulama dosyaları bir web adresinde durur; bu dosyalarda hasta verisi yoktur. Hasta kayıtları yalnızca sizin cihazlarınızda, parolanızla AES-256 şifreli tutulur. Google Drive'a giden kopya da şifrelidir; Google içeriği okuyamaz.

1Uygulamayı yayına alın (GitHub Pages, ücretsiz)

  1. github.com adresinde hesap açın (varsa giriş yapın).
  2. Sağ üstteki + simgesi → New repository. İsim: poliklinik. Görünürlük: Public. Ücretsiz GitHub Pages bunu gerektirir. Bu klasörde yalnızca uygulama kodu bulunur, hasta verisi bulunmaz. Create repository'ye tıklayın.
  3. Açılan sayfada uploading an existing file bağlantısına tıklayın. Size gönderilen zip dosyasını bilgisayarınızda açın. İçindeki tüm dosyaları ve icons klasörünü sayfaya sürükleyin. Zip'in kendisini değil, içindekileri sürükleyin. Ardından Commit changes'e tıklayın.
  4. Settings → Pages. Source: Deploy from a branch. Branch: main, klasör: / (root) → Save.
  5. 1–2 dakika sonra uygulamanın adresi aynı sayfada görünür: https://KULLANICIADINIZ.github.io/poliklinik/. Bu adresi not edin.

Alternatif: Web sitenizi yöneten kişi bu dosyaları hasta.drgailgasimov.com gibi bir alt alan adına da koyabilir. Tek şart https olmasıdır. Bu durumda 2. adımdaki “origin” olarak o adresi yazın.

2Google Drive eşitlemesi için istemci kimliği oluşturun

Bu adım, uygulamanın kendi Google hesabınızdaki gizli bir klasöre şifreli dosya yazabilmesi içindir. Uygulama yalnızca drive.appdata iznini ister. Google bu izni “hassas olmayan” kapsamda sınıflandırır: uygulama sadece kendi verisini görür, Drive'daki diğer dosyalarınıza erişemez.

2a. Proje ve Drive API

  1. console.cloud.google.com adresine Gmail hesabınızla girin. Üstteki proje seçiciden New project → ad: Poliklinik Defteri → Create.
  2. Sol menü: APIs & Services → Library. “Google Drive API” arayın → Enable.

2b. Uygulama tanıtımı (Google Auth Platform)

  1. Sol menü: Google Auth Platform. İlk açılışta Get started'a tıklayın.
  2. App name: Poliklinik Defteri. User support email: kendi Gmail adresiniz. Audience: External. İletişim e-postası: yine kendi adresiniz. Koşulları onaylayıp Create'e tıklayın.
  3. Audience sayfası → Test users → Add users → kendi Gmail adresinizi ekleyin. Uygulama “Testing” durumunda kalabilir; yalnızca siz kullanacaksınız.
  4. Data Access sayfası → Add or remove scopes. Listede …/auth/drive.appdata satırını işaretleyin → Update → Save.

2c. İstemci kimliği (Client ID)

  1. Clients sayfası → Create client. Application type: Web application. Name: Poliklinik Defteri.
  2. Authorized JavaScript origins → Add URI → https://KULLANICIADINIZ.github.io. Sonuna /poliklinik eklemeyin ve sonunda “/” olmasın. Redirect URI gerekmez.
  3. Create'e tıklayın. Açılan pencerede Client ID'yi kopyalayın; ….apps.googleusercontent.com ile biter. Client secret gerekmez, uygulama kullanmaz.

Google ayarların etkinleşmesinin 5 dakika ile birkaç saat sürebileceğini belirtiyor. İlk denemede origin_mismatch hatası görürseniz biraz bekleyip tekrar deneyin.

3Bilgisayarda ilk kurulum

  1. Chrome'da 1. adımdaki adresi açın.
  2. Yeni defter oluştur → parolanızı iki kez yazın. Parola en az 8 karakter olmalı. Daha uzun bir cümle parolası tercih edin, örneğin Diz-Omuz-Kalça-2026!.
  3. Sağ üstteki dişli simgesi (Ayarlar) → Google istemci kimliği alanına Client ID'yi yapıştırın → Kimliği kaydet.
  4. Google'a bağlan ve eşitle'ye tıklayın → Gmail hesabınızı seçin. “Google bu uygulamayı doğrulamadı” uyarısı görebilirsiniz. Uygulama size ait olduğu için Devam'a tıklayıp izni onaylayın.
  5. Üstteki düğme yeşil nokta + “Eşitlendi” gösterdiğinde bağlantı tamamdır.
  6. Chrome adres çubuğunun sağındaki yükle simgesine tıklayın. Uygulama masaüstünde ayrı bir pencere olarak açılır.

4Android telefona kurulum

  1. Telefonda Chrome ile aynı adresi açın.
  2. Sağ üstteki ⋮ menüsü → Uygulamayı yükle (bazı sürümlerde Ana ekrana ekle). Ana ekranda logolu “Poliklinik” simgesi oluşur.
  3. Simgeden açın → Google Drive'daki defterimi aç → aynı Client ID'yi yapıştırın → Kimliği kaydet.
  4. Google ile giriş yap ve defteri bul → aynı Gmail hesabını seçin → defter parolanızı girin.
  5. Hasta kartındaki büyük telefon düğmesine dokunduğunuzda telefonun arama ekranı numara yazılı olarak açılır.

5Günlük kullanım

İşNasıl

6Güvenlik ve KVKK notları

  • Parola unutulursa kayıtlar açılamaz. Bu bir eksiklik değil, şifrelemenin doğal sonucudur. Parolanızı kâğıda yazıp evde güvenli bir yerde saklayın.
  • Parolayı değiştirirseniz diğer cihazda da Ayarlar → Parolayı değiştir ile aynı yeni parolayı ayarlayın.
  • Telefonunuzda ekran kilidi (PIN/parmak izi) açık olsun. Uygulamayı ortak kullanılan hastane bilgisayarlarına kurmayın.
  • TC, telefon ve tanı birlikte özel nitelikli kişisel veridir (KVKK). Hastane bilgi sistemi dışında kişisel kayıt tutmayla ilgili hastanenizin KVKK sorumlusunun görüşünü alın. Bu kılavuz hukuki görüş değildir.
  • Cihazınızı değiştirirken veya başkasına verirken Ayarlar → Bu cihazdan sil kullanın.
